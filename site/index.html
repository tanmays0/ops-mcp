Cursor setup

Wire the local stdio server. Secrets stay in .env on your machine.

  1. Clone tanmays0/ops-mcp and run uv sync
  2. Copy .env.example → .env (token, DSN, FS roots)
  3. Optional: docker compose up -d for the seeded Postgres demo
  4. Launch: uv run python -m ops_mcp (or let Cursor spawn it)
  5. Point Cursor at the config below — replace absolute paths
Never paste GitHub tokens or database URLs into this public site. Load them only from local environment files.
