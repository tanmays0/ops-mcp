MCP control plane · docs & simulated demos

Not just tool access — gated tool access.

OpsMCP is a FastMCP server that lets an AI agent operate GitHub, Postgres, deploy status, and a sandboxed filesystem — only after fail-closed security checks. Credentials stay in the local server process.

FastMCP Python 3.12 Postgres GitHub API sqlglot Docker
Try the playground View on GitHub

This site is static. The real MCP server runs locally over stdio — nothing here holds your tokens.

How it works

The agent proposes a tool call. The security/ layer is the gate — adapters never see rejected input.

1 Agent / Cursor proposes tool + args
→
2 MCP stdio FastMCP server
→
GATE security/ sandbox · SQL AST · dry_run · rate limit
→
3 adapters/ GitHub · Postgres · FS
→
4 Real systems only if allowed

Package layout: tools/ · security/ · adapters/ · config.py
